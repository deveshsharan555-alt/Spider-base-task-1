# Machine Learning Projects

This repository contains two machine learning projects developed using Python:

### 1. Fashion MNIST Classification

A neural network built using PyTorch to classify clothing images from the Fashion MNIST dataset into different categories.

### 2. PDF Chatbot (RAG)

A Retrieval-Augmented Generation (RAG) chatbot that allows users to upload PDF documents and ask questions about their content using an LLM.

### Technologies Used

* Python
* PyTorch
* Streamlit
* LangChain
* FAISS
* Hugging Face
* PyPDF2

These projects demonstrate applications of Deep Learning, Natural Language Processing, and AI-powered document retrieval.
